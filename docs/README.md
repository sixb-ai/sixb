# Get started

Sixb is a TypeScript framework for building a living model of your domain. Represent the things
you work with and how they relate, connect them to your data, and build apps and AI that can read
and act on that model.

## Quickstart

Sixb runs on **Bun**. Install [Bun](https://bun.sh) **1.4.2 or later**, then create and start your
project:

```bash
bun create sixb my-app
cd my-app
bun install
bun run dev
```

Everything runs locally. No database setup or API keys required.

Open **[localhost:3001](http://localhost:3001)** and select **Locate** to see the starter app track
Sentinel-6B using public orbital data. Keep the terminal running; locating the satellite requires
an internet connection.

You can also explore your project in **[Atlas](http://localhost:3000)** or view the
**[API documentation](http://localhost:3002/docs)**.
